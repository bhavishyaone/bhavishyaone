## About Me

I'm a Full-Stack Developer focused on building practical web applications and understanding how systems work behind the scenes. I enjoy turning ideas into working products and improving them step by step.

**Currently working on**  
Building full-stack MERN applications that solve real problems, such as authentication systems, dashboards, and CRUD-based platforms.

**Looking to collaborate on**  
Open-source projects or early-stage product ideas where I can contribute frontend or backend features.

**Looking for help with**  
System design fundamentals, database modeling, and backend scalability.

**Currently learning**  
Data Structures & Algorithms, writing cleaner production-ready backend code, and exploring AI/ML fundamentals.

**Ask me about**  
JavaScript, React, Node.js, REST APIs, MongoDB, Git, and project structuring.

**Fun fact**  
Most of my learning happens while fixing bugs at 2 AM!
